# Builds

> 真实做过的实验、实现与 Agent 相关项目。

这个目录用于存放实际搭建、测试或验证过的内容。

## 包含内容

- `agents/`  
  Agent 项目、原型或实验。

- `automations/`  
  面向高频任务或高杠杆任务的自动化流程。

- `benchmarks/`  
  对比实验、评测设置与实际测试结果。

- `harness/`  
  用于验证、复现、评分或受控实验的支撑系统。

## 什么内容适合放在这里

`builds/` 中的内容至少应满足以下之一：

- 有可运行代码
- 有清晰的搭建或使用说明
- 有明确的输入与输出
- 有可观察的结果或行为

## 什么内容不适合放在这里

这里不适合放：

- 只有想法、没有实现的内容
- 外部资料整理
- 临时草稿
- 非结构化碎片记录

## 判断标准

一个 build 应该体现的不只是“理解过”，而是“真正做出来并验证过”。
