# Builds

> Real experiments, implementations, and working agent-related projects.

This directory contains things I actually built, tested, or prototyped.

## Includes

- `agents/`  
  Agent-based projects, prototypes, or experiments.

- `automations/`  
  Automated workflows for repetitive or high-leverage tasks.

- `benchmarks/`  
  Comparisons, evaluation setups, and practical testing results.

- `harness/`  
  Supporting systems for validation, repeatability, scoring, or controlled experimentation.

## What belongs here

Content in `builds/` should have at least one of the following:

- runnable code
- clear setup
- concrete inputs and outputs
- observable result or behavior

## What does not belong here

This is not for:

- pure ideas without implementation
- collected references
- temporary scratch notes
- unstructured drafts

## Rule of thumb

A build should show that something was not only understood, but also turned into practice.
