# Repository instructions for agents

AgentRecord is a narrow, personal repository for durable analysis of agents themselves.

When adding or revising content:

1. Put new substantive writing in `analyses/`.
2. Do not create new top-level directories or new asset types without first presenting an exact change list to the user.
3. Do not add domain engineering implementations, project logs, tool tutorials, news summaries, prompt collections, or skill collections.
4. An external case may be cited as evidence, but its background, commands, experiment output, and solution stay in its domain repository.
5. A new article must form an independent judgment; a source roundup or chat summary is not enough.
6. Separate verified facts, structural analogies, inferences, hypotheses, and conclusions.
7. Prefer primary sources, search for counterevidence, and state uncertainty and validity boundaries.
8. Do not treat user beliefs, retrieved memories, popularity, or model self-review as factual evidence.
9. Revise an existing article when new evidence changes the same question; do not create parallel documents merely to preserve old wording.
10. Prefer one clear thematic commit over file-by-file commits.

Before changing repository structure, list the proposed changes and wait for user confirmation.
