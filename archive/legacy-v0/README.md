# Legacy v0

这里保存 AgentRecord 初版按内容形态组织的材料：

- `builds/`
- `journal/`
- `playbooks/`
- `reviews/`

这些文件没有被删除，但不再属于当前知识主线。原因是按工具、载体或输出类型分类，容易持续积累“看过什么、用过什么”，却丢失“为什么这样判断、如何证伪、何时失效”。

迁移旧内容时不要原样复制：

1. 能恢复真实问题和证据链的，改写为 Case；
2. 能形成可复现实验的，改写为 Experiment；
3. 仅介绍工具用法的，保留在此处或删除；
4. 跨案例成立的部分，再独立抽取为 Pattern；
5. 不把旧文的结论状态自动视为 `tested`。
