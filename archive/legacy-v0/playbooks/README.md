# Playbooks

> Reusable prompts, workflows, skills, and templates.

This directory contains practical assets that can be copied, adapted, and reused directly.

## Includes

- `prompts/`  
  Prompt patterns for analysis, writing, coding, research, and task execution.

- `workflows/`  
  Step-by-step workflows for recurring agent tasks.

- `skills/`  
  Focused operational know-how for specific tools, scenarios, or problem types.

- `templates/`  
  Reusable templates for structured output, documentation, and execution.

## What belongs here

Content in `playbooks/` should be:

- directly reusable
- easy to adapt
- clear in purpose
- lightweight but practical

## What does not belong here

This is not for:

- raw notes
- unfinished experiments
- link collections
- vague ideas without usage context

## Rule of thumb

A playbook should help someone go from input to usable output faster and more reliably.
