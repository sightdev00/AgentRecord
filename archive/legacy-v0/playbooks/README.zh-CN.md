# Playbooks

> 可直接复用的 prompts、workflows、skills 与 templates。

这个目录用于存放能够直接复制、修改、复用的实践资产。

## 包含内容

- `prompts/`  
  用于分析、写作、编码、研究和任务执行的 Prompt 模板或模式。

- `workflows/`  
  面向重复性 Agent 任务的步骤化流程。

- `skills/`  
  针对特定工具、场景或问题类型的操作型方法。

- `templates/`  
  用于结构化输出、文档编写和任务执行的通用模板。

## 什么内容适合放在这里

`playbooks/` 中的内容应当具备以下特征：

- 可以直接复用
- 易于修改和迁移
- 目标清晰
- 轻量但实用

## 什么内容不适合放在这里

这里不适合放：

- 原始笔记
- 未完成的实验
- 纯链接收藏
- 没有使用场景的模糊想法

## 判断标准

一个 playbook 应该能够帮助使用者更快、更稳定地从输入走到可用输出。
