# Journal

> Ongoing notes on what I explored, built, and learned.

This directory records continuous progress over time.

## Includes

- `weekly/`  
  Short weekly logs of exploration, experiments, and key takeaways.

- `monthly/`  
  Higher-level summaries of progress, themes, and direction changes.

- `CHANGELOG.md`  
  Notable repository-level updates and structural changes.

## Purpose

The journal exists to make progress visible.

It helps track:

- what was explored
- what was built
- what changed
- what is worth doing next

## Writing style

Entries should be:

- short
- concrete
- reflective
- easy to scan later

## Rule of thumb

The journal is not for polished essays.  
It is for preserving momentum, decisions, and learning over time.
