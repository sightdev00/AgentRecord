# Decisions

Decision 记录当前在明确范围内采用的实践原则。

它必须说明：

- 适用范围和责任人；
- 所依据的 Case、Pattern 或 Experiment；
- 考虑并放弃过的方案；
- 尚未解决的不确定性；
- 验收方式；
- 何时复议，出现什么证据就撤销。

这里没有永久“最佳实践”，只有带边界、可追溯、可撤销的决定。

新建 Decision 使用 [`decision.md`](../_meta/templates/decision.md)。
