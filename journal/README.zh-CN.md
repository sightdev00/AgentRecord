# Journal

> 持续记录近期探索、构建与思考。

这个目录用于按时间记录 Agent 相关的学习、实验、变化与阶段性成果。

## 包含内容

- `weekly/`  
  每周的简短记录，关注探索、实验与关键收获。

- `monthly/`  
  每月的阶段性总结，关注主线进展、方向变化与整体判断。

- `CHANGELOG.md`  
  仓库层面的重要更新与结构变化记录。

## 目的

Journal 的存在不是为了写长文，而是为了让进展可见。

它主要记录：

- 最近看了什么
- 最近做了什么
- 哪些判断发生了变化
- 下一步值得继续做什么

## 写作风格

这里的内容应尽量做到：

- 简短
- 具体
- 有反思
- 方便后续快速回看

## 判断标准

Journal 不是精修文章区，而是用于保留行动轨迹、关键决策与持续积累的地方。
