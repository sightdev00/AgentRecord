# Foundations

这里存放 Agent 基础问题的理论分析与概念辨析。

Foundation 的职责是建立问题空间，不是给出脱离案例的“万能方法”。每篇内容必须区分：

- 学术理论原本讨论的对象；
- 它与 Agent 问题之间的直接证据；
- 只是结构相似的类比；
- 尚待案例或实验验证的工程推断。
